# 🚀 Expo-101

¡Bienvenido a mi primera aplicación móvil creada con **React Native** y **Expo**! 📱✨

---

## 🛠️ Requisitos Previos

Antes de empezar, asegúrate de tener instalado:
* [Node.js](https://nodejs.org) 🟢
* [Git](https://git-scm.com) 🐙
* La app **Expo Go** instalada en tu celular (iOS o Android) 📲

---

## 🚀 Comandos Básicos para Empezar

Si clonas este repositorio en otra computadora o quieres volver a abrirlo, usa estos comandos en tu terminal:

### 1. 📥 Descargar las dependencias
Instala todas las librerías necesarias del proyecto (como la carpeta `node_modules` que no se sube a GitHub):
```bash
npm install
```

### 2. 🔑 Iniciar Sesión en Expo (Solo la primera vez)
Si Expo te pide conectar tu cuenta para usar los túneles de desarrollo:
```bash
npx expo login
```

### 3. ⚡ Iniciar el Servidor de Desarrollo
Enciende el proyecto para generar el código QR:
```bash
npx expo start --tunnel
```
*💡 Nota: Usamos `--tunnel` para evitar problemas de conexión y bloqueos de red o Wi-Fi.*

---

## 📲 ¿Cómo probarlo en tu celular?

1. Abre la app **Expo Go** en tu teléfono.
2. Escanea el **código QR** que aparece en la terminal:
   * **Android:** Escanéalo directamente desde la opción dentro de Expo Go.
   * **iPhone:** Usa la cámara normal de tu celular y dale clic al enlace amarillo.
3. ¡Mira cómo tus cambios se actualizan en vivo en tu pantalla! ⚡🎨
